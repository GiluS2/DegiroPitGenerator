# DegiroPitGenerator

## How to run the release
1. Download the latest Release from Github
2. Download `Transactions.csv`and `Account.csv` from Degiro. It can be found under "Activities -> Transactions -> Download". Please change the report start date to "any day before you created Degiro account" and end date to today.
3. Put the downloaded files in the main folder
4. Start DegiroPitGenerator.exe with year param (for instance `2025`)
5. After a couple of seconds the Json file with all crucial PIT-38 fields opens
